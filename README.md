# Surefit - Ai Workout Coach

Guided strength sessions for iPhone, with a timer or a rep counter and on-screen form cues.

Built with Expo and React Native.

## Features
- Beginner plan, workout player, and on-device progress (free)
- Intermediate and Advanced plans, plus a custom generator (Momentum Pro)
- StoreKit 2 purchases via expo-iap (no RevenueCat)

## Run
```bash
npm ci
npx expo start
```

## Scripts
- `npm run typecheck` – syntax check all JavaScript entry files
- `npm run lint` – same as typecheck
